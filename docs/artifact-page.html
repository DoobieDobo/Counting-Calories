Counting Calories

The prices are in calories.

Pick a dish, then shop for it one ingredient at a time. Every choice comes off a budget worked out from your own height, weight and activity level — and the checkout says no if you can't afford it.

Same dish, same slot, a six-fold difference. Thirty-nine dishes across five menus — Filipino, American, Arabic, Chinese, and a breakfast menu of silogs and diner plates — each with a shelf like this behind every ingredient.

Playing it

The game is a 300 KB app and this page can only hold about 36 KB, so it lives elsewhere. Three ways in:

  1. Open the file Claude sent you The entire game in one HTML file. Save it, tap it in Downloads, open it with Chrome. Runs offline and remembers where you got to.
  2. Run it from the repo npm install then npm run dev in DoobieDobo/Counting-Calories.
  3. Host it on GitHub Pages A permanent URL that rebuilds on every push. The workflow is already in the repo — it needs the repository set to public and Pages switched on.

Co-op works too: two to four people on one screen, budgets pooled into a single pot, and the person who commits each ingredient rotates — so every choice has to be argued for out loud. Every dish is cooked one serving per player, so the food on the table scales with the budget behind it.

A game, not medical advice. Calorie figures come from standard composition tables and the budget from the Mifflin-St Jeor equation — built to make the cost of food choices felt, not to manage a health condition.
